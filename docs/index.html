quant-finance-py

A Python/NumPy port of Quant-Finance-Library — the Java reference implementation, v1.17.0 — with NumPy as the only runtime dependency (no scipy, no pandas). Pricing, rates, credit, risk, volatility, backtesting, FX dealing, central risk book, alpha research, microstructure, execution, wire formats and persistence: 223 modules in 26 packages, algorithm-faithful to the Java source so its hand-pinned test values transfer at the same tolerances. Every public entry point rejects NaN, infinity, empty input and out-of-range confidence with ValueError, and an identical probe battery runs against Java, C++ and Python (156 labels) and diffs to zero mismatches.

The latest review found that risk_metrics and var_engine.tail clamped with max(0.0, nan), so a NaN in a return series came back as VaR = ES = 0; both now raise ValueError before any clamp, and confidence levels are gated to (0, 1). The same round fixed frtb_es.stress_calibrated_es, whose MAR33.6 floor sat on ES_RS/ES_RC instead of ES_FC/ES_RC; gave every Black–Scholes greek its closed-form vol = 0 limit instead of ZeroDivisionError; made implied_vol raise on a NaN price or an expired option instead of returning the 1e-4 bracket bound; made GARCH/GJR fits raise on NaN, zero-variance or undefined likelihood instead of returning default parameters; and made the LEARN.md cross-port verification command actually run (compare.py now resolves repo-relative paths). What's inside

util and data: the bedrock

util/math_utils holds 27 public numerical primitives — mean/variance, percentile, Cholesky with the Java pivot rules, Acklam norm_inv, Abramowitz–Stegun norm_cdf, Lanczos log_gamma, Lentz incomplete beta, t_cdf. data provides Bar (validates high ≥ low as the Java record does), BarSeries (strictly increasing epoch-millisecond timestamps), a CSV loader with a pinned European-decimal regression, a series aligner, corporate actions, a point-in-time universe and QFLT tick files.

pricing: Black–Scholes and its siblings

Black–Scholes with every greek including the vol = 0 limits and a bracket-checked implied vol; Black-76, higher-order greeks, CRR binomial tree, digitals, barriers and touches (Reiner–Rubinstein), vanna-volga, Margrabe/Kirk spreads, quanto, variance swap, Kemna–Vorst and Turnbull–Wakeman Asians, structured notes, autocallables, Heston in the little-trap form, SABR (Hagan), vol surface, forward curve, dividends, fair value and triangular arbitrage — 22 modules.

rates, credit, commodities, markets

YieldCurve bootstrap over validated whole-year pillars, a bond pricer with bracket-checked YTM, Nelson–Siegel and Svensson fits, a swap pricer (annuity/par/DV01), Vasicek/CIR/Hull–White, key-rate durations, swaptions and caps. credit: piecewise-constant hazard bootstrap (O'Kane–Turnbull), CDS pricer with the sub-grid maturity gate, Z-spread, CVA. Futures-curve carry and roll yield; index divisor continuity; private-markets IRR/TVPI/KS-PME/Geltner desmoothing.

risk: what a risk committee asks for

Four VaR flavours plus ES, Euler component VaR, Ledoit–Wolf shrinkage, peaks-over-threshold EVT (PWM fit, McNeil–Frey VaR/ES), stress and reverse stress, FRTB ES with the MAR33.5 liquidity-horizon cascade and MAR33.6 stress calibration, P&L attribution, VaR backtests (Kupiec, Christoffersen, Basel traffic light), PCA, Gaussian/t copulas, HHI concentration, counterparty PFE and settlement risk. VaR and ES are positive loss numbers — fractions in risk_metrics, currency units in var_engine.

volatility and indicators

EWMA (RiskMetrics λ = 0.94), GARCH/GJR/EGARCH fits on the Java grids, HAR-RV, a model-free (VIX-style) index, Parkinson/Garman–Klass/Rogers–Satchell/Yang–Zhang range estimators, AIC/BIC selection and vol decomposition; a batch + streaming indicator set (SMA/EMA/RSI/MACD/Bollinger/ATR/VWAP…). Student-t GARCH likelihoods and standard errors are out of scope and say so.

backtest: engine, validation, portfolio

Backtester with 5 strategies, cost and execution models under a cash-conservation contract, walk-forward with warm folds and grid search, plus trade/performance/drawdown analytics. validation/ carries purged K-fold with embargo, CSCV probability of backtest overfitting, block bootstrap, deflated Sharpe and Monte Carlo trade reshuffle; portfolio/ position sizing (Kelly, risk parity, max-Sharpe), optimizers, a portfolio backtester and cross-sectional momentum. Long-only, single-instrument by design.

Desk engines: fx, crb, alpha, microstructure, execution

FX conventions and calendars, swap points, FX swaps/NDFs, a premium-adjusted delta-quoted vol surface, tier book and LP scorecard/router; a central risk book with factor-space netting, skewed quoting, internalization, an L1 hedge optimizer and P&L ledger; the alpha research pipeline (factors, evaluator, validation, construction, Fama–MacBeth, online learner); Almgren–Chriss, Kyle's lambda, VPIN, Hawkes, Lee–Ready, Avellaneda–Stoikov with a degraded() feed flag; TWAP/VWAP/POV/IS schedulers, smart and adaptive routing, dark-pool MEQ simulation.

Wire formats, persistence, simulation

FIX codec, framer, encoder and view; ITCH codec, an L3 book builder with exact queue position, NBBO; SBE byte-exact flyweights. persist.Checkpoint mirrors the Java file format (magic, version byte, named sections, atomic os.replace commit) and is wired into LpScorecard, EwmaCovariance and VolumeCurve. sim is Monte Carlo on a bit-exact SplittableRandom; dsl is the no-lookahead strategy builder; ml has GBDT, an HMM regime detector and robust anomaly detection.

Cross-port harness and testing approach

tools/crossport/ holds Probe.java (the source of truth for label order), probe.py, probe.cpp, the three checked-in outputs and compare.py; tests/test_crossport_compare.py pins that the documented invocation prints 156 labels, 0 mismatches. The 1027-test suite transcribes the Java suite's hand-pinned values, adds NaN-poison contracts for every gate, implied-vol round trips, finite-difference greek checks, GARCH garbage/recovery, curve hygiene and known-answer tie rules for CSCV.

Real-world usage notes

Rates, yields and vols are annualized decimals; time is in years; theta is per year and vega/rho per 1.00 change; timestamps are epoch milliseconds. Inputs are gated, not repaired — the only documented exceptions are AvellanedaStoikov (non-finite variance sets degraded()) and KylesLambda (skips non-finite samples). conditional_var and var_engine.tail differ by one order statistic at small n; CSCV counts an exact-median rank as overfit. Python is the algorithms lane for research, teaching and cross-checking numbers, not the hot path.

Quick start

git clone https://github.com/AshJha0/quant-finance-py.git
cd quant-finance-py

# Python >= 3.11, NumPy >= 1.26 is the only runtime dependency
python3 -m pip install -e .[dev]
python3 -m pytest -q                       # 1027 tests, about 30 s

# without installing: PYTHONPATH=src python3 ...
# re-run the cross-port guarantee against the checked-in Java output
PYTHONPATH=src python3 tools/crossport/probe.py > /tmp/py_check.out
python3 tools/crossport/compare.py tools/crossport/java.out /tmp/py_check.out
# -> 156 labels, 0 mismatches
